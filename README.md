🚀 Repo describing my homelab server setup
- Currently I am running two wyse mini pcs with pihole, wireguard unbound on one, and a minecraft classic server with a samba file share on the other

🏗️ Structure
- /docs contains pdf of product docs
- /runbooks contains details of how to set up each component including extra scripts
- /scripts extra scripts including a monitors for system updates
- /servers each server with docker compose ymls

🕸️ https://david-baker.co.uk for details of setup
